# GitHub Pages sürümü

Bu sürüm tamamen herkese açıktır; giriş şifresi, admin paneli ve sunucu yoktur. Bu nedenle ücretsizdir ve doğrudan GitHub Pages'e yüklenir.

## PDF eklemek

1. PDF dosyasını `assets/exams/` klasörüne yükleyin.
2. `exams.json` dosyasına aynı yapıda yeni bir kayıt ekleyin. `pdf` alanı örneğin `assets/exams/kimya-11.pdf` olur.
3. GitHub'a gönderin. Site otomatik güncellenir.

## Yayınlamak

1. Bu klasörün **içindekileri** yeni GitHub reposunun köküne yükleyin.
2. Repository → **Settings → Pages** → Source: **Deploy from a branch** seçin.
3. Branch olarak `main`, klasör olarak `/ (root)` seçip Save'e basın.
4. Birkaç dakika sonra GitHub Pages bağlantınız görünür.

PDF bağlantıları ve arşiv içeriği herkes tarafından görülebilir.
